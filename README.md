## What this portfolio covers

- **Website design & development:** Squarespace 7.1 design, page layouts, site structure, and responsive presentation.
- **Content strategy & copywriting:** Original website copy, page organization, property messaging, and visitor-focused content.
- **SEO:** On-page optimization, page titles, meta descriptions, and content improvements.
- **Technical customization:** Custom CSS and HTML, JSON-LD / Schema.org structured data, and technical site enhancements.
- **Digital strategy:** Consistent digital experiences across multiple hospitality properties.
