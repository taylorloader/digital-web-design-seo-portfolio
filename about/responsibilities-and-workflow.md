# Responsibilities & workflow

## Role

Digital web design and strategy work spanning website design and development, content strategy, SEO, technical customization, and ongoing website management.

## Typical responsibilities

1. Understand the property, audience, services, and business goals.
2. Organize information into a clear website structure.
3. Design and build pages in Squarespace 7.1.
4. Write original, useful website copy.
5. Improve page titles, metadata, and on-page SEO.
6. Apply custom CSS and HTML where appropriate.
7. Implement and refine JSON-LD / Schema.org structured data.
8. Review, maintain, and improve the live website.

## Tools and platforms

- Squarespace 7.1
- CSS
- HTML
- JSON-LD / Schema.org

## Scope and accuracy

This portfolio describes hands-on work in website design and production, content, SEO, and front-end customization. It does not claim JavaScript development, backend engineering, or full-stack development.

Examples are shared selectively and should be sanitized and approved for public portfolio use.
