# Denham Hospitality Organization — Multi-property digital ecosystem

## Overview

This portfolio documents website work across multiple hospitality properties associated with Denham Hospitality Organization (DHO).

The work is approached as a connected portfolio of property websites: each hotel needs a clear, distinct identity and useful visitor experience, while the overall collection benefits from consistency in quality, content, and digital presentation.

## Properties represented

- [Best Western Premier Denham Inn & Suites](https://www.bestwesterndenham.com/)
- [Best Western Plus Edmonton Airport Hotel](https://www.bwedmontonairporthotel.com/)
- [Best Western Camrose](https://www.bestwesterncamrose.com/)
- Best Western Lacombe — website project in progress.
- Denham Hospitality Organization — corporate website project in progress.

## My contribution

I design, build, write, optimize, and manage the websites. My responsibilities include Squarespace 7.1 implementation, original website copy, SEO content and metadata, CSS and HTML customization, and JSON-LD / Schema.org structured data.

## Strategic considerations

- Preserve the distinct identity and information needs of each property.
- Create consistent, usable page experiences across the portfolio.
- Organize content so guests can find relevant accommodation, dining, and event information.
- Support discoverability through clear content, metadata, and structured data.
- Consider opportunities for appropriate cross-property navigation and shared information.

This overview describes the context of the website work; it does not imply that the portfolio author owns the organization or its brands.
